# 发热治理与电流估算（thermal-haptic-opt）

电机：2804，Rs=2.55Ω/相（估算用 2.50Ω），7 对极，KV≈220（Ke=0.0434 V·s/rad 线-线），Ls=0.86mH，额定 0.5A。
铜损 P = 3/2 · Iq² · Rs。

## 旧版根因

| # | 问题 | 后果 |
|---|------|------|
| 1 | `BOARD_V_SUPPLY=9` 而实物 12V | 所有电压指令 ×1.33 |
| 2 | 闭环只限压 2.5V（实际 3.33V），无电流限制 | 堵转/卡位峰值 ≈1.3A（2.6×额定） |
| 3 | 锁角模式速度环 I=4 | 积分饱和，静止也憋电流 |
| 4 | 开环 Uq≡Vlim 1V（实际 1.33V） | 持续 0.53A，≈1.07W，必烫 |
| 5 | 对齐 3.5V（实际 4.67V） | ≈1.9A 上电冲击 |
| 6 | 单点对齐、失败后 zero=0 照样出力 | 零点偏差 → d 轴电流纯发热 |
| 7 | FOC 环 1kHz、无反电动势补偿 | 快拧时短路制动电流 Ke·ω/Rs |
| 8 | 无空闲休眠 | 驱动持续开关 |

## 新策略

- 供电 Kconfig `KNOB_SUPPLY_MV`（默认 12000），运行时 `vsup`。
- 所有闭环：电流指令 → `Uq = clamp(I, ±Ilim)·Rs + 0.9·Ke/√3·ω`，Ud≡0。
- 峰值 0.35A（Kconfig），I²t 热模型 τ=4s，RMS>0.2A 时自动降额。
- 锁角：无积分 PD + 0.6° 死区。触感：格位 + snap + 死区，静止零电流。
- 静止 1.5s → EN=0 休眠；转动 >2° 唤醒。
- 开环：0.2A×Rs=0.5V，10s 超时。
- 对齐 0.5A（1.25V），正反扫一圈 112 点圆周平均精校零点，存 NVS（`recal` 清除）。
